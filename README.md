Lux Chibi Image Generator
A customizable chibi prompt generator created by Glo Sis Designs / Shenetria Perkins.

Overview
The Lux Chibi Image Generator is a browser-based prompt builder designed to help users create polished chibi-style image prompts with customizable character features, styling options, backgrounds, typography, and mood direction.

This generator is designed for users who want a guided way to build prompts for:

stylized chibi characters
cartoon-inspired character art
glossy character renders
coloring page prompts
anime-inspired prompts
graphic comic illustration prompts
prompt-based image generation workflows
Features
button-based character builder
instant vibe creator
customizable cartoon type selection
typography controls
prompt output generator
15-second video script generator
multi-select options for supported sections
age-aware prompt safety adjustments
copy prompt and copy video tools
Included File
index.html — main generator file
How To Use
Open index.html in your browser.
Choose your character options.
Add any extra details in the Additional Options area if needed.
Click Generate Prompt.
Copy the generated prompt and use it in your image-generation workflow.
Best Results
Start with Cartoon Type first.
Keep your selections focused and consistent.
For child prompts, use age-appropriate options.
Use Additional Options only for extra details that are not already covered by the builder.
